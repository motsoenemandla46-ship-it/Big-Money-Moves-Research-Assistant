# SA Money Moves Research Assistant

A dark documentary-style web app for building structured business and rise-and-fall research reports.

## Features
- Topic, company/person/industry, research question, and documentary angle inputs
- Progress indicator and beginner-friendly UX
- Structured interview-style research output sections
- Timeline and source tables
- Visual brainstorming for documentary scenes
- Copy and export report buttons
- Demo research generation that can be connected to live web search or an AI API later

## Quick start

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite in your browser.

## Build

```bash
npm run build
```

## Notes
This prototype is intentionally designed to avoid inventing facts. It uses a research template that encourages source verification, publication dates, and distinction between facts, interpretation, and uncertainty.
